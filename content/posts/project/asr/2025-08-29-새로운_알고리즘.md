## 청크 위치 기반 confidence 가중치 알고리즘

청크의 처음과 끝에 위치하는 단어를 어떻게 필터링 하는지에 따라 WER이 최대 +-2% 정도 차이가 나는 것을 실험을 통해 알 수 있었다.

1. 초기 알고리즘인 청크 위치 기반 confidence 가중치를 가하고, confidence의 threshold 기준으로 confidence가 낮으면 제거 하는 알고리즘 사용
2. 1번과 함께, 이전 청크에서 인식한 단어 리스트의 마지막 단어를 제거, 현재 청크에서 인식한 첫 번째 단어 제거를 추가
3. 2번을 제거하고, 다시 1번으로 돌아가되 exponent를 변수로 설정

{{< figure src="/images/project/asr/새로운_알고리즘/Confidence_가중치_알고리즘.png" alt="subject" class="center" width="80%" >}}

3 > 1 > 2 순으로 WER이 나타난다.  

2번을 적용하기에는 타당하지 않다.
인식이 잘 된 단어를 제거하게 될 수도 있으며, 청크내에서의 단어 위치를 판단하여 제거하는 것은 아니다.
결국 현재 알고리즘으로는 청크의 앞과 끝에 위치하는 잘못 전사된 단어를 제거하는 것은 어렵다는것을 알 수 있었다.

{{< raw >}}
$$
    W_{c_\text{new}} =
    \begin{cases}
        W_c \cdot \left(\tfrac{W_{cd}}{B}\right)^{E},         & \text{if } W_{cd} < B \ \land \ W_{cd} \leq C_{cd}, \\[6pt]
        W_c,                                                  & \text{if } W_{cd} < C_{d} - B,                      \\[6pt]
        W_c \cdot \left(\tfrac{C_{d} - W_{cd}}{B}\right)^{E}, & \text{otherwise}.
    \end{cases}
$$
{{</ raw >}}

기존 수식은 위와 같다.
이러한 수식은 머신러닝 알고리즘을 통해 유사하게 구현할 수 있을 수도 있지만, y라벨이 없어 학습은 불가능하다.
그러나, WER이 있어 WER을 loss로 생각하여 최적화를 할 수는 있다.
미분 불가능하지만 확률기반 수치미분인 SPSA(Simultaneous Perturbation Stochastic Approximation) 알고리즘을 적용해 볼만하다고 생각한다.

{{< figure src="/images/project/asr/새로운_알고리즘/머신러닝_알고리즘.png" alt="subject" class="center" width="80%" >}}

최적화 과정에서도 문제점이 있다.
confidence 모델 학습과 confidence를 제외한 하이퍼파라미터 학습이 병행되어야한다는 것이다.
현재로써는, 잘 나온 하이퍼파라미터를 기준으로 confidence 모델을 먼저 학습시키고, 다시 하이퍼파라미터를 학습시키는 방법으로 병행할 것 같다.

## 단어 그룹에서의 단어 선택 알고리즘

단어 그룹에서 단어 선택을 하는 알고리즘 또한 WER에 큰 영향을 준다.
현재 고안한 방법은 3가지 이다.

1. Confidence 기반 선택
2. Confidence와 직전 단어와의 코사인 유사도 기반 선택
3. Confidence와 직전 단어와의 코사인 유사도, 현재 단어 그룹의 평균 임베딩 벡터와의 코사인 유사도 기반 선택

{{< figure src="/images/project/asr/새로운_알고리즘/선택_알고리즘.png" alt="subject" class="center" width="80%" >}}

전부 따로 실험을 통해 최적화 하고, 결과를 비교해서 가장 좋은 결과를 나타내는 알고리즘을 선택할 예정이다.
